# Backup Project

## Overview
Modular Bash scripts for automated backup operations — copy, log,
source selection, and destination handling.

## Components
- `backup.sh`: Main script to trigger backup
- `backup_copy.sh`: Handles file copying
- `backup_dest.sh`: Manages destination paths
- `backup_log.sh`: Logs backup activity
- `backup_sources.sh`: Defines source files/folders

## Usage
./backup.sh
